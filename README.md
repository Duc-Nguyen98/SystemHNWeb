# SystemHNWeb — Hoa Nam CMS UI/UX

Repository riêng cho giao diện UI/UX hệ thống CMS/WMS Hoa Nam.

## Phạm vi

- Review board xác thực, dashboard, danh mục SKU, danh mục sản phẩm, đại lý/nơi nhận và bệnh/lỗi.
- Palette Hoa Nam Design v2: `#0C6286`, `#0C5D7D`, `#5E93A7`, `#FAFCFC`.
- Giữ nguyên các hành vi prototype hiện có; không chứa mã Scanner mobile hoặc Product Preview trong bản publish.

## Chạy local

```bash
npm install
npm run dev
```

Đây là UI/UX prototype độc lập. API, RBAC và dữ liệu vận hành thật không nằm trong repository này.
